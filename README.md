# Rundown

Your daily briefing, distilled.

## Structure

```
api/    — Node.js + TypeScript backend
ios/    — SwiftUI iOS app
docs/   — Project documentation
```

## Getting Started

### API

```bash
cd api
npm install
cp .env.example .env   # fill in your keys
npm run dev
```

### iOS

Open the Xcode project in `ios/` (created separately).
